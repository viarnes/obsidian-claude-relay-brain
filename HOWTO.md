# Obsidian 101
On Windows and Linux, use `Ctrl` wherever this note says `Cmd`.

- **Link everything.** People, initiatives, providers and dates go in `[[wikilinks]]`. Linking to a note that doesn't exist yet is fine: it marks something worth writing later
- **Always link dates**: `[[2026-10-16]]`, never plain text. That's how notes connect to the daily timeline (very useful for future us)
- **Don't link the main project** (eg: the company name). Everything here is about it, so that node would connect to everything and mean nothing
- **Keep notes small.** One person, project or idea per note. Prefer bullets over prose. If a note gets too long, split it into smaller notes
- Press `Cmd+P` to open Obsidian's command palette
- Press `Cmd+G` to open the brain graph
- Press `Cmd+Shift+G` to open the local graph of a node
# New notes
- Press `Cmd+N` to create a new private note
# Daily notes
- Press `Cmd+Shift+D` to create today's daily note
- Useful to organize the day (tip: ask Claude to craft a custom skill that builds it for you)
- Mention meetings, priorities, blockers, findings, etc.
# Random thoughts
- Press `Cmd+R` to create a random note (named with the current date and time)
- Useful for thoughts that deserve their own note
- No need to link it to anything yet
# Finding things
Notes inside private aren't sorted into folders, so search instead of browsing:
- Press `Cmd+Shift+F` to search inside every note, or open the **Backlinks** pane on a node to see every note that mentions it
- Press `Cmd+K` to find a node by name
# Plugins
- **Natural Language Dates**: type `@today` or `@next monday` to insert date links
- **Symbols Prettifier**: turns `->` into → and similar
- **Relay**: used for collaborative work
# Other hotkeys
- `Alt+↑` / `Alt+↓`: move the current line up or down
- `Cmd+Shift+S`: strikethrough
